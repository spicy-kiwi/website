# Archiv

Liegt außerhalb von `content/` und `layouts/`, wird von Hugo also nicht gebaut.

- `rezepte-nicht-in-trello/` — Rezepte ohne Trello-Karte (u. a. argentinisch)
- `layouts/` — Templates, die gerade nicht gebraucht werden: Zutaten-Liste (Zutaten liegen in `content.staging/`), Shortcode `nicht-in-trello`, Tag-Intros für Tags ohne Rezepte
- `data/` — Zutatenlisten ohne Rezept (`risotto_base`, `risotto_beetroot`)

Zurückholen: Datei an den gleichen Pfad unter `layouts/` bzw. `data/` verschieben.
